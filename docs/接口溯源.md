## 三、为什么你搜不到（三条原因）

1. **不在入口包**：接口在 `shared-account-http` 这个**独立 chunk**，
   而 `main-*.js` 里只有埋点常量。搜入口包会漏。
2. **英文标识符**：代码里是 `daily-checkin` / `checkin-status`，没有中文。
3. **中文文案来自服务端**：界面上的「签到」二字由接口返回的
   `claim_button_text` 字段下发。实测**这批 web JS 里没有「签到」两个字**，
   所以搜中文必然 0 命中。

## 六、请求格式与鉴权方式（网关自证）

### 请求格式

```http
POST /v2/billing/meter/daily-checkin HTTP/1.1      ← 桌面通道（有 /v2）
Host: www.workbuddy.cn
Content-Type: application/json
Accept: application/json
Authorization: Bearer <token>                       ← 仅当有 token 时附加
Cookie: session=...; session_2=...                  ← withCredentials 默认 true

{}
```

- **请求体是空对象 `{}`**，无任何业务参数（源码：`b.post("/billing/meter/daily-checkin", {})`）。
- Web 通道前缀为空：`/billing/meter/daily-checkin`（源码 `CloudAccountRepo.billingPrefix = ""`）。

### Authorization 头的构造（源码原文）

`packages/agent-provider/src/http/http-service.ts` @137541682：

```js
registerDefaultRequestInterceptor() {
  this.axiosInstance.interceptors.request.use((requestConfig) => {
    requestConfig._authGeneration = this.authGeneration;
    if (this.config.authToken) {
      requestConfig.headers = requestConfig.headers || {};
      requestConfig.headers["Authorization"] = `Bearer ${this.config.authToken}`;  // 原样拼接
    }
    return requestConfig;
  }, (error) => Promise.reject(error));
}
```

axios 基线（@137539549）：

```js
this.axiosInstance = axios.create({
  baseURL: config.baseURL?.replace(/\/$/, "") || "",
  timeout: config.timeout || 60000,
  withCredentials: config.withCredentials !== false,     // 默认 true → 带 cookie
  headers: { "Content-Type": "application/json", "Accept": "application/json" }
});
```

**token 格式结论**：就是一个**字符串原样拼在 `Bearer ` 后面** —— 无编码、无签名、无固定前缀约定。
`setAuthToken()` 全部调用点只有两处（均为 Provider 构造时），
token 由**上层会话层传入**，即「服务端签发的会话凭证」，**不能自行构造**。

### 鉴权实质：cookie `session`（网关自证）

对受保护路径发无凭据请求，**响应头里被删空的 cookie 就是它认的凭据**：

```http
# POST /v2/billing/meter/checkin-status
HTTP/1.1 401 Authorization Required
Server: APISIX/3.9.1
Set-Cookie: session=;   Path=/v2;                HttpOnly      ← /v2 专属作用域
Set-Cookie: session=;   Domain=www.workbuddy.cn; HttpOnly
Set-Cookie: session_2=; Domain=www.workbuddy.cn; HttpOnly
Set-Cookie: session=;   Path=/; Max-Age=0

# GET /activity/growth/profile
Set-Cookie: session=;   Path=/activity;          HttpOnly      ← /activity 专属作用域
```

**结论**：鉴权凭据是名为 **`session`（以及 `session_2`）的 cookie**，
且**按路径分段作用域**（`/v2`、`/activity`、`/` 各一份）。
这解释了为何 Web 端抓包看到的是 cookie 而非 Bearer —— Web 走 cookie，桌面才额外带 Bearer。
